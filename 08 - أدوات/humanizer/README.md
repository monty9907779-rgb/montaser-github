# Humanizer Tool

أداة صفحة واحدة (HTML) لتحويل النص المكتوب بالذكاء الاصطناعي إلى نص يبدو طبيعيًا. تعمل بالعربي والإنجليزي بدون سيرفر.

## التشغيل
افتح `index.html` في المتصفح مباشرة.

## ماذا تفعل
- تحذف العبارات الآلية المعتادة ("في الختام"، "من الجدير بالذكر"، "In conclusion"، "delve"...)
- تستبدل الشرطة الطويلة (—) بفاصلة
- تزيل تنسيق Markdown والإيموجي
- تقسّم الجمل الطويلة وتنوّع بدايات الجمل المتكررة
- تبسّط الكلمات المنمّقة وتضيف اختصارات إنجليزية (it's, don't)
- تعرض مؤشر "آلية النص" قبل وبعد، وتميّز الكلمات المتغيرة

## وضع متقدم (اختياري)
إعادة صياغة كاملة عبر Anthropic API. المفتاح يُحفظ في localStorage بالمتصفح فقط ولا يُرسل إلا إلى api.anthropic.com.
